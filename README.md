# ことのは｜ウェブ体験用データ

## スマホ向け更新版

画面切り替えタブ、ダミーの時刻・端末枠、説明フッターを除去しました。子ども選択からアプリ内の操作だけで進めます。画面幅に合わせた表示、長い文章の折り返し、横向き・短い画面でのスクロール、ボトムシートの高さ制限、入力時の表示領域への追従を追加しています。全スマホ端末での実機動作保証ではありません。実際にデモで使う端末で事前に確認してください。

## 開き方

1. ZIPを解凍します。
2. `index.html` をChrome、Safari、Edgeなどのブラウザで開きます。
3. 子どもを選んで、日記を開く・めくる・読む・記録する操作を試せます。

インストールやビルド、APIキーは不要です。写真・ステッカーはHTMLに埋め込んであります。フォントなどの外部リソースを読み込むため、インターネット接続のある状態でお試しください。

## スマートフォンからURLで試す場合

`index.html` を静的サイトに対応したウェブサーバーへ配置し、そのHTTPS URLをスマートフォンのブラウザで開きます。このZIPに公開URLは含まれておらず、まだインターネットへの公開はしていません。iPhone/iPadのファイルのプレビューではなく、ウェブサーバー上のURLをSafariで開く方法が適しています。

## 試せる機能

- 子どもごとの切り替え
- 日記の開閉と、見開きのページめくり
- 1ページの拡大表示、横スワイプ、プログレスバーでの移動
- ボトムシートでの記録・編集、写真や連絡帳画像の添付
- 「文章を整える」のオン／オフ、ページの生成プレビュー
- 確認後に日記へ追加する操作（表示中のセッション内のみ）

## 重要：完成アプリではなく、操作確認用プロトタイプです

- 追加・編集した日記と添付写真は再読み込みやタブを閉じると失われます。大切な記録の保存先として使わないでください。画面位置だけがブラウザに保持される場合があります。
- 下書きの自動保存はありません。
- 文章整形は一部の例文向けの簡易処理で、AIには接続していません。
- ステッカーは生成済み素材を文章のキーワードに合わせて選びます。任意の文章から新しい絵を生成する機能ではありません。
- 連絡帳の文字読み取り、写真の背景切り抜きは未実装です。
- アカウント登録、子ども情報の編集、クラウド保存、端末間同期はありません。
- 子どものプロフィール写真は架空のAI生成サンプルです。日付・月齢もサンプル値です。
- 添付画像や入力文を外部AIへ送る処理はありません。試用には個人情報を含まないサンプルをご利用ください。

## 同梱ファイル

- `index.html`：ブラウザで開く本体。画像・スタイル・操作処理を含みます。
- `source/fragment.html`：編集用の元データ。本体として開く場合は `index.html` を使ってください。
- `assets/stickers-simple-v4.png`：デフォルメ版ステッカー素材。
- `assets/child-portraits.jpg`：子どものプロフィール用写真素材。
- `assets/stickers-simple-v4-prompt.md`：イラストの生成指示と方式の記録。

元データを編集しただけでは本体には反映されません。変更後は本体の再書き出しが必要です。

## 検証範囲

画面切り替え、文章整形チェック、追加・編集、プログレスバー移動の処理と、ZIP内ファイルの整合性を確認済みです。実機ブラウザでのアニメーション・外部フォントの読み込みは未確認です。
